# BSD Router Project: Open Source Router Distribution

*Don't buy a router: download it!*

BSD Router Project (BSDRP) is an embedded free and open source software router
distribution based on [FreeBSD](http://www.freebsd.org) with
[FRRouting](https://frrouting.org/) and [Bird](http://bird.network.cz/).
