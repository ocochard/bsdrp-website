## Contributors and embedded software

The authoritative list of BSDRP contributors, reused patches, and
embedded software (with licenses and upstream URLs) lives in the
[`AUTHORS`](https://github.com/ocochard/BSDRP/blob/master/BSDRP/Files/root/AUTHORS)
file of the BSDRP repository. It is also shipped on every BSDRP image
at `/AUTHORS`.

The authors of BSDRP would like to thank the upstream authors of every
package listed there for their work.
