## Developer guidelines

### General

This project try to follow the Bible: [Producting Open Source Software, How to Run a Successful Free Software Project by Karl Fogel](http://www.producingoss.com/)

### Copyright

No personnal name as copyright in the source code: Kept “The BSDRP Development Team”.

Real Authors names are wrote:

- On the [Contributors](../contributors.md) pages
- In the file [AUTHORS](https://github.com/ocochard/BSDRP/blob/master/BSDRP/Files/root/AUTHORS)

This prevent too lot’s of authors names in head of each file.

### Technical choices

All shell scripts need to use sh (#!/bin/sh) for maximum compatibly.
